## 模块 F：人格核心（首先执行）

### F1. 核心特质与核心恐惧

从语言习惯推断大五人格，并深挖**核心恐惧**——那才是行为模式的真正内驱力。

**三种核心恐惧：**

| 类型 | 表现 |
|---|---|
| **被抛弃恐惧**（Fear of Abandonment） | 高频确认、需要秒回、过度讨好、反复问「你是不是不想理我」 |
| **被吞噬/丧失控制恐惧**（Fear of Engulfment） | 回避亲密、强调独立、升温时突然消失 |
| **被贬低恐惧**（Fear of Inadequacy） | 自尊心防御强、不愿暴露脆弱、吹嘘或防御性攻击 |

**语言信号 → 大五维度：**

| 语言信号 | 推断维度 |
|---|---|
| 频繁提成就/不想虚度/规划未来 | 高尽责性 |
| 「我觉得」「也许」「好像」「感觉」高频 | 高神经质（情绪敏感） |
| 主动分享脆弱后立刻转移话题 | 防御性开放（渴望被理解但怕暴露） |
| 对他人社交异常敏感、反复追问 | 低安全感 + 高嫉妒倾向 |
| 用逻辑/理性解释情感决定 | 理性化防御 |
| 反复要求「你说真的」「你是不是骗我」 | 高确定性需求 |
| 「我们」高频、少分「你和我」 | 高亲和力 |
| 以安排事务为主、少有情感表达 | 高尽责性 + 事务导向 |
| 大量感叹号/emoji/情感词 | 高外向性 |
| 能清醒评价自己的行为 | 高元认知 |

> ⚠️ 这套映射是**启发式**，不是量表。得出的大五值必须标 `evidence_level`。

### F2. 防御机制识别（最关键）

对每种机制输出四件事：① 名称 ② 触发情境 ③ 聊天原文 ④ 真实含义解码

```
防御性撤退（Protective Withdrawal）
  信号："算了" / "随便你" / "不想说了" / "没什么"
  关键：出现在什么情境？冲突后 / 被忽视后 / 还是主动说的？
  真实含义：情绪低落时的自我保护，不是理性评估。

理性化（Rationalization）
  信号：用逻辑论证"为什么不行"，但行为相反
  真实含义：感情/情绪已卷入，用理智撑门面。

投射性怀疑（Projective Suspicion）
  信号："你肯定对别人也这样" / "你来者不拒"
  真实含义：把内心恐惧（"我不够特别"）投射为质疑。
            不是在攻击，是在问"我在你心里是不是特别的"。

情感否认（Emotional Denial）
  信号："我无所谓" 但行为高度卷入
  真实含义：用否认保护自主感——"是我选择不太在乎"。

回避型开放（Selective Disclosure）
  信号：分享私密后突然切话题或变冷
  真实含义：在测试反应。没被接住就关门。

转移性幽默（Deflecting Humor）
  信号：每次深一点的话题都用梗/表情/玩笑接掉
  真实含义：用幽默维持"轻松"，代价是任何话都无法落地。
  ⚠️ 这条在本项目里极常见，是首要排查项。
```

### F3. 底层需求 → 表面行为解码

| 表面行为 | 底层需求 | 解码 |
|---|---|---|
| 反复确认真心 | 高确定性需求 | 要的不是"我喜欢你"，是时间累积的一致性 |
| 提事业/不想被耽误 | 怕因感情失去自我 | 保护"即使失去你也还有自己" |
| 说你"来者不拒" | 渴望成为唯一 | 需要排他感和被选中感 |
| "路还长，不着急" | 给自己留退路 | 降低当下脆弱暴露 |
| 忽冷忽热 | 高度卷入但未决定 | 用冷热测试耐受力和真心 |
| 撤回消息 | 说了太多真心话 | 防御性收回，重建心理安全距离 |
| 用「损」代替「夸」 | 想表达亲近但不愿承认 | 贬损语域就是她的亲昵语域 |
| 用「问」代替「说」 | 想继续但要假装不是自己想 | 提问既能续聊又不用承认 |
| 用「要」代替「给」 | 想确认对方愿不愿为自己付出 | 金额小到不计较，测的是动作 |

### F4. 信任架构

总结信任建立模式：
- 信任需要什么条件（一致性 / 时间 / 具体行动 / 情感回应）
- 什么会触发防御（被忽视 / 不特别 / 暴露后没被接住 / 被公开牵连）
- 历史经历对当前信任模式的影响（有线索必须引用原文）

## 模块 L：生活层面（本 skill 独有）

> 这一层回答的是「她平时是什么样的人」，而不是「她对你怎么样」。**没有这一层，画像只是关系的切片。**

### L1. 社交角色

从对话的第三方提及里重建她的社交地图：

- 她主动提到的人名 → 谁在她生活里有分量
- 她怎么称呼这些人（外号？全名？）→ 亲疏
- 她抱怨谁、维护谁 → 立场
- 她在群体里的位置（被骂时是她先炸还是先忍？）

**输出格式：**

```
人物         出现次数   她怎么提      情感倾向
白凯迪         N         "我同桌"     中性/调侃
王梓旭         N         "死绿茶"     敌对
```

### L2. 日常节律

- 活跃时段（几点开始、几点结束）
- 什么日子不出现（周末？考试周？）
- 她的一天怎么过（上课 / 作业 / 补习 / 家里）
- 睡眠状况（几点睡、睡多少、上课睡不睡）

**这一层用来判断「什么时候找她最容易得到回应」。**

### L3. 价值观与优先序

从她用钱、用时间、评价别人的方式里推断：

- 钱：她在意吗？怎么花？（点外卖、报销、凑整）
- 成绩/作业：在意程度，是糊弄还是真写
- 朋友 vs 家人 vs 独处：她把时间花在哪
- 她佩服什么人、看不起什么人

### L4. 边界与雷区

**必须有「她实际表现出不适」的原文才能写。**

常见的雷区形态：
- 被公开牵连（评论区、群里）
- 被追问不想说的事
- 被否定她所在意的东西（长相、成绩、家人）
- 被安排/被使唤（这个要看她愿不愿意）

**输出：**

| 雷区 | 触发原文 | 她的反应 |
|---|---|---|
| … | 「…」 | 沉默 / 怼回来 / 拉黑 |

### L5. 语域差异（对谁说什么）

**这是最能说明问题的一层。**

同一个人对不同的人，用词、句长、表情密度都不同。**如果能拿到至少两组对话，比较：**

| 维度 | 对你 | 对别人 |
|---|---|---|
| 消息中位长度 | | |
| 疑问句比例 | | |
| 表情/表情包密度 | | |
| 主动发起比例 | | |
| 是否发语音 | | |

**只有一组数据时，明确写「无法比较」，不要编。**

## 模块 B：沟通与情感模式

### B1. 依恋类型

**必须先判证据是否足够，不足就留空。**

| 类型 | 聊天信号 |
|---|---|
| 安全型 | 能舒适表达需求、不过度解读沉默、冲突后能修复 |
| 焦虑型 | 频繁确认、未秒回就发「？」、语气稍冷就过度解读 |
| 回避型 | 情感表达后转移话题、回复简短、从不谈感情 |
| 恐惧型 | 时而热烈时而消失、靠近后拉开、撤回大量情感消息 |

> ⚠️ **只有「高主动 + 零情感表达」这种混合模式，不足以判定任何一种。** 必须看到她在压力下的反应，或她自己的解释。

### B2. 沟通风格

主导型 / 迎合型 / 情绪型 / 事务型 / 爆发型

### B3. 情绪调节风格

过度表达 / 压抑回避 / 健康表达

### B4. 爱的语言

肯定的言辞 / 精心的时刻 / 接受礼物 / 服务的行为 / 身体的接触

### B5. 情感可得性

高 / 中 / 低，并说明**她的可得性是有条件的还是无条件的**。

## 语言模式（贯穿全程）

读记录时同步观察：

- **代词**：「我们」高频 → 建立共同体；坚持「你」「我」分开 → 维持边界
- **时态**：频繁「以后/将来」→ 结合是否有落地行动
- **条件句**：「如果你…」「等你…」→ 设门槛
- **模糊词**：「也许/可能/感觉」密度 → 不确定度
- **情绪词正负比**
- **撤回**：防御性收回还是习惯
- **提问率**：谁在问、问什么 —— **提问方通常是想继续对话的一方**
- **消息长度中位数**：短句多不代表冷淡，要跟她对别人的比
