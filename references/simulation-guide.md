# 回应模拟指南

> **这个模块不生成「她会说的话」。它用历史语境预测她的反应模式。**
>
> 区别很重要：编一句像她语气的台词，看起来很厉害，但没有任何预测价值。
> 而「过去 5 次类似语境里，她 4 次这样回、1 次不回」——这个能用。

---

## 输入

用户给一句**他准备发的话**（可以是草稿，也可以只是意思）。

如果有画像文件，先读 `<bundle>/profile/profile.json`，用它校准判断。

---

## 流程

### Step 1 · 拆解这句话

把候选句拆成可检索的要素：

| 要素 | 问题 |
|---|---|
| **意图** | 是接梗 / 关心 / 请求 / 邀约 / 表态 / 敷衍？ |
| **强度** | 轻（玩笑）还是重（认真、涉及关系）？ |
| **指向** | 指向她（夸她/问她）还是指向我（说自己）还是指向事？ |
| **给她留的口** | 她回一句就能结束吗？还是要她想？ |

### Step 2 · 检索相似语境

```bash
python scripts/retrieve.py --jsonl "<messages.jsonl>" --query "他想发的那句话" -k 15
```

脚本会返回历史上语境最接近的若干次「他说 → 她回」的实际片段。

**看三件事：**

1. **她的回应长度**（比平时长 = 有兴趣；比平时短 = 这话题她不接）
2. **她的回应延迟**（秒回 vs 隔很久）
3. **她是否继续发起下一轮**（她回完还接一句 = 她想继续）

### Step 3 · 归纳她的反应模式

把检索结果按语境分类，输出成表格：

```
类似语境            样本数    她的典型反应          续聊概率
我自嘲/贬低自己       6        「猪」「你蠢吗」      5/6
我认真关心她状态      3        「嗯」「不知道」+沉默  1/3
我邀约/提见面         0        —                    无法评估
```

**样本数为 0 的类别，明确写「没有历史样本」—— 这本身就是信息：你们从没做过这件事。**

### Step 4 · 给出预测

```
## 预测

最可能（≈X%）：…
  依据：<日期> 她在类似语境下的原话「…」

次可能（≈Y%）：…
  依据：…

小概率（≈Z%）：…
  依据：…

## 主要风险

<这句话最容易在哪个点翻车>

## 如果想调整

<换成什么形态成功率更高，为什么>
```

## 硬规则

### 1. 不许编台词

- ✅ 可以：「她大概率会回一句短损，类似『你是猪吗』这种，因为她过去 6 次都这样」
- ❌ 不可以：「她会说：『你才是猪吧哈哈哈』」——这是编的，哪怕语气很像

**要引用，就引真实历史原话并标日期。**

### 2. 概率只能是区间，不能是精确数字

写「大概率 / 差不多一半 / 小概率」，不写「73.5%」。样本通常只有几次，精确到小数点是假的。

### 3. 没有相似样本时，直说

> 「你们从来没在这个语境下说过话，所以我无法预测。这本身说明：这条路径是新的。」

**这比硬猜有用。**

### 4. 遇到这几类，停止模拟

- 她明确表达过拒绝 / 不适 / 不想继续 → 不模拟「怎么让她改变主意」
- 用户在设计试探、制造嫉妒、故意冷落 → 拒绝，说明理由
- 涉及她在别处的隐私（朋友圈、和别人聊天）→ 不参与

---

## 输出长度

**一屏能看完。** 用户是拿着手机等一句话，不是要读论文。

- 预测部分不超过 12 行
- 风险部分 2–3 句
- 调整建议最多 2 个版本
